DISEÑADA CON PRIVACIDAD

Tu contraseña maestra
no sale de la sesión.

Nexo no necesita una cuenta para funcionar. La bóveda se cifra localmente y la contraseña maestra solo se mantiene en la sesión activa mientras la bóveda está desbloqueada.

01

Cifrado local

Los datos de la bóveda se protegen mediante Web Crypto API.

02

Sin autenticación remota

El alias es solo local. No hay cuentas ni sincronización con un servidor.

03

Sesión controlada

Bloquea la bóveda cuando quieras y se limpia al cerrar la última ventana de Chrome.

EMPIEZA EN MINUTOS

Instala Nexo
desde el código fuente.

Nexo todavía se prueba como extensión sin empaquetar. Puedes revisar el código y generar tu propia copia local.

  1. 1

    Clona o descarga

    Obtén el repositorio desde GitHub e instala Node.js LTS.

  2. 2

    Genera la extensión

    npm install && npm run build
  3. 3

    Carga la carpeta dist/

    Abre chrome://extensions/, activa Modo desarrollador y elige Cargar descomprimida.
